# 🎯 Scrum Board

**Scrum Board** — это интерактивное консольное приложение для управления задачами по методологии Scrum, построенное на современном C++ с использованием библиотеки FTXUI для создания красивого текстового интерфейса.

## ✨ Основные возможности

### 📋 Управление задачами
- ✅ **Создание задач** с названием, описанием и приоритетом
- 🔄 **Перемещение задач** между колонками (Backlog → In Progress → Done)
- 🗑️ **Удаление задач** 

### 👥 Управление разработчиками
- ➕ **Добавление разработчиков**
- ❌ **Удаление разработчиков**
- 👤 **Назначение разработчиков** на задачи

### 📊 Визуализация рабочего процесса
- 🎨 **Интерактивная доска** с колонками:
  - **Backlog** — бэклог задач
  - **Assigned** — назначенные задачи
  - **In Progress** — задачи в работе
  - **Blocked** — заблокированные задачи
  - **Done** — завершенные задачи

### 💾 Система сохранения
- 📂 **Загрузка доски** из файла
- 🔄 **Сохранение доски** в файл
- ✅ **Валидация** файлов перед загрузкой

## 🚀 Установка и запуск

### Предварительные требования

- **C++ компилятор** с поддержкой C++17 
- **CMake** 3.14 или выше

### Сборка проекта

```bash
# Клонирование репозитория
git clone https://github.com/LehaKrechet/text_scrum_board.git
cd scrum-board

# Создание директории для сборки
mkdir build && cd build

# Конфигурация проекта
cmake ..
# Сборка
make
# Запуск приложения
./text_scrum-board

# Для Windows
cmake ..
cmake --build . --config Release
.\Release\text_scrum_board.exe


```

### Установка зависимостей

#### Ubuntu/Debian
```bash
sudo apt update

sudo apt install cmake make
```

## 🎮 Использование

### 🏠 Стартовое меню
При запуске приложения отображается стартовое меню с опциями:
- **Create New Board** — создать новую доску
- **Load Existing Board** — загрузить существующую доску

### 📊 Основной интерфейс

#### Вкладки управления:
1. **Board View** — просмотр всей доски
2. **Create Task** — создание новых задач
3. **Manage Developers** — управление разработчиками
4. **Manage Tasks** — перемещение и удаление задач
5. **Assign Developer** — назначение разработчиков на задачи

#### Панель управления:
- **Save Board** — сохранить текущее состояние
- **Load Board** — загрузить доску из файла
- **Exit** — выход из приложения
